# DevTools Timeline Viewer

**DevTools Timeline Viewer is sunset.** We recommend [trace.cafe](https://trace.cafe/) as an alternative:

- Drag-and-drop any trace (`.json` or `.gz`) for an instant shareable link
- Runs an up-to-date Chrome DevTools Performance panel
- Zero Google Drive OAuth or CORS setup required
- One-click toggle to inspect the same trace in Perfetto UI

---

The historical source code is preserved on the [`pre-sunset`](https://github.com/ChromeDevTools/timeline-viewer/tree/pre-sunset) branch.
